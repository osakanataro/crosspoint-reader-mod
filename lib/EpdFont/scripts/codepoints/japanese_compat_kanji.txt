# CJK互換漢字（U+F900-FAFF）コードポイントリスト
#
# japanese_jis0213.txt はJIS X 0213が定義する統合済みの字体（Unicode正規化上の
# 基本多言語面のCJK統合漢字）だけを対象としており、同じ字の「互換漢字」版
# （出版社の組版システムが特定の字体を指定する際に使うことがある、統合前の
# 重複コードポイント）は含まない。この一覧は実書籍で使用が確認された
# CJK互換漢字を1文字ずつ手作業で追加する場所。
#
# 使い方: 追加したい符号位置を1行に1つ、4桁の16進数（先頭の "U+" は付けない）で
# 追記する。BIZUDGothic/BIZUDMincho/NotoSansJPは既にintervals（cjk-symbols経由で
# F900-FAFFがcjkプリセットに含まれる）とcodepoints_fileの両方が設定済みなので、
# このファイルに1行足すだけで次回生成に反映される。
#
# F9EC: 溺（できる/おぼれる）。統合先は U+6EBA（同じくjapanese_jis0213.txtに
#   含まれる）。2026-08-23: 商業EPUB955冊調査で10冊に出現を確認。
# F999: 蓮（はす、人名でも使用）。統合先は U+84EE。5冊に出現。
# F993: 煉（「煉獄」等）。統合先は U+7149。3冊に出現。
#
# BIZ UDGothic/BIZ UDMincho は F9EC と F993 の字形を持たない（F999 のみ持つ）ため、
# この一覧に載っていても3書体すべてに入るとは限らない。字形の無い書体では
# ChapterHtmlSlimParser が統合先の符号位置に置き換えて描く。
