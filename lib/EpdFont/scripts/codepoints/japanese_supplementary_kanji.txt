# 補助面（U+10000超）の日本語漢字コードポイントリスト
#
# JIS X 0213 の基本収録（japanese_jis0213.txt）は基本多言語面（BMP、U+0000-FFFF）に
# 収まる字のみを対象としており、CJK拡張B以降の補助面漢字は含まない。この一覧は
# 実書籍で使用が確認された補助面漢字を1文字ずつ手作業で追加する場所。
#
# 使い方: 追加したい符号位置を1行に1つ、4〜6桁の16進数（先頭の "U+" は付けない）で
# 追記し、sd-fonts.yaml の該当ファミリーの intervals に "cjk-ext-supplementary" を、
# codepoints_file にこのファイルを加える（BIZUDGothic/BIZUDMincho/NotoSansJPは
# 既に両方が設定済みなので、このファイルに1行足すだけで次回生成に反映される）。
#
# 20B9F: 𠮟る（しかる）。JIS X 0213での正式な字体。「叱」（U+53F1、BMP内）は
#   同じ読みの古い異体字で、japanese_jis0213.txt 側に別途含まれている。
#   2026-08-23: なろう・カクヨム取得513冊の実データ調査で、513冊中6冊に出現を確認
#   （転生勇者の三軒隣んちの俺、異端のダークヒーラー…、転生爺のいんちき帝王学…、他3冊）。
